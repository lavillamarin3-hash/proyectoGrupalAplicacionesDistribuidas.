# Nexo · Aplicaciones Distribuidas

Proyecto grupal de Aplicaciones Distribuidas (ESPE). Tecnología acordada: Java + Oracle. La aplicación contempla los módulos Selección, Nómina, Contabilidad y Biblioteca.

El desarrollo del módulo **Selección (Villamarín)** se prepara en una rama independiente y se integrará mediante Pull Request.

El proyecto debe respetar los requisitos de pantallas CRUD, evaluación cabecera/detalle, ranking, reportes por fechas e integración con Nómina. Este archivo inicializa el repositorio; los módulos se incorporarán mediante ramas.
